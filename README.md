# IA aplicada a Ecommerce, Contenido y Automatización

Repositorio de formación y experimentos. No es un producto — es el registro del proceso de
aprendizaje: laboratorios, prompts, workflows y proyectos chicos de cada fase del plan.

> "No quiero aprender simplemente a usar IA. Quiero comprender los conceptos y principios
> que están detrás de las herramientas actuales para poder adaptarme a cualquier nuevo
> modelo, plataforma o tecnología que aparezca en el futuro."

## Regla de aprendizaje

Cuando una IA resuelva algo importante, no alcanza con que el resultado funcione. Hay que
entender qué hizo, por qué funciona, qué conceptos hay detrás, qué partes conviene saber
modificar manualmente, qué errores podrían aparecer y qué alternativas existen.

Pregunta guía: **¿qué pasaría si mañana Claude, ChatGPT o cualquier otra herramienta dejara
de existir?** El conocimiento adquirido tiene que permitir aprender rápido cualquier
herramienta equivalente.

## Estructura

Cada carpeta es una fase del roadmap de 12 meses. Adentro de cada una va el trabajo
correspondiente (notebooks, scripts, docs, prompts) más un `README.md` con los objetivos
y el estado.

| Carpeta | Fase | Foco |
|---|---|---|
| `fase-0-preparacion` | Semana 1 | Setup: proyecto, repo, documentación, portfolio |
| `fase-1-fundamentos` | Meses 1-2 | IA/ML/DL, LLMs, embeddings, RAG, agentes (teoría) |
| `fase-2-llm-trabajo-profesional` | Meses 2-3 | Prompt/context engineering, structured outputs |
| `fase-3-creacion-contenido` | Meses 3-4 | Imagen, video, copywriting, contenido con IA |
| `fase-4-ecommerce` | Meses 4-6 | UX, CRO, SEO, Ads, analytics — sobre el ecommerce de aromas |
| `fase-5-automatizacion` | Meses 6-8 | APIs, webhooks, n8n/Make/Zapier |
| `fase-6-agentes` | Meses 8-10 | Agentes, function calling, RAG, multi-agente |
| `fase-7-datos` | Meses 10-11 | SQL, Python, análisis y visualización de datos |
| `fase-8-portfolio` | Meses 11-12 | Casos de estudio, portfolio, LinkedIn, CV |
| `templates` | — | Plantilla de documentación de proyectos |
